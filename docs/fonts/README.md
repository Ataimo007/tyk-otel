# Fonts for the deck

The Tyk Design System sets headlines and body text in **Archivo** and eyebrows, labels and code in **Space Mono**. Both are free Google Fonts (SIL Open Font License, see `OFL.txt`).

- **Google Slides:** nothing to do. Both fonts are built in.
- **PowerPoint or Keynote:** double-click each `.ttf` file and choose *Install Font* before opening the deck. Without them, the app substitutes a different font, and the mint highlight bars under the headline key words won't line up with the text.
